# Banking & Finance Analytics Dashboard

## Project Overview

The Banking & Finance Analytics Dashboard is an interactive data visualization project developed using Power BI. The dashboard analyzes banking and financial data to provide meaningful insights into loan distribution, customer activity, branch performance, and overall financial trends.

The project transforms raw data into interactive visual reports that can help users understand business performance and support data-driven decision-making.

## Project Objectives

* Analyze loan status and distribution.
* Compare loan amounts across different branches.
* Identify and analyze top customers.
* Understand branch-wise loan performance.
* Track important financial KPIs.
* Provide interactive filters for exploring the data.
* Generate meaningful business insights from banking data.

## Key Features

## Data Preparation

The data was prepared and transformed before visualization. Power Query was used for data cleaning and transformation, including handling data inconsistencies and preparing the dataset for analysis.

## Dashboard

The Power BI dashboard provides an interactive interface where users can filter and analyze banking information based on different categories such as branches, loan status, and customers.

## Project Outcome

This project demonstrates how Power BI can be used to transform raw banking data into meaningful and interactive business insights. The dashboard makes it easier to identify trends, compare branch performance, analyze customers, and understand loan-related information.
